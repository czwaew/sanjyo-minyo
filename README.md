# 三条民謡保存会ホームページ Ver.2

## GitHubへ上書きする方法
1. ZIPをダブルクリックして解凍します。
2. 中の7ファイルと `images` フォルダをすべて選択します。
3. GitHub Desktopの `sanjo-minyo` フォルダへコピーします。
4. 同名ファイルの確認では「置き換える」を選択します。
5. GitHub Desktopで Summary に「ホームページVer.2へ更新」と入力します。
6. `Commit to main` → `Push origin` の順に押します。

## 更新方法
- お知らせ・出演予定：`data.js`
- メール送信先：`app.js` の `CONTACT_EMAIL`
- 活動写真：`images` 内の仮画像を実際の写真へ差し替え
